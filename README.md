# J.R Tecnologia

Site institucional das soluções **J.R Driver**, **J.R Logística Comercial** e **J.R Finance**, preparado para publicação no GitHub Pages.

## Produtos apresentados

- **J.R Driver:** aplicativo Android para motoristas e entregadores. O APK Alpha permanece disponível para testes.
- **J.R Logística Comercial:** sistema Windows independente para gestão operacional e financeira. Informações comerciais e compra são tratadas diretamente pela J.R.
- **J.R Finance:** sistema Windows independente para controle financeiro pessoal ou empresarial, com usuários locais separados. Compra única para **1 computador Windows**, independentemente do número de perfis locais nesse computador. Preço de lançamento aprovado: **R$ 19,90 por 15 dias a contar do início efetivo das vendas**; depois, **R$ 29,90**. Esta versão do site apresenta o produto e permite manifestar interesse, mas **ainda não oferece compra ou download do Finance**.

Os produtos compartilham a identidade da J.R, mas funcionam de forma independente. A compra e a licença do J.R Comercial não dão acesso ao J.R Finance.

## Antes de colocar o J.R Finance à venda

Implementar e testar a ativação vinculada a 1 computador; definir transferência de licença em caso de troca ou defeito do PC, política de suporte e atualizações, termos de venda, instalador para distribuição, checkout específico do Finance e data efetiva de início da oferta de 15 dias. Não apontar o botão de compra do Finance para o checkout do Comercial; são produtos distintos. Não iniciar contagem regressiva antes da publicação das vendas.

- `index.html`: página institucional unificada
