O J.R Finance cobra mensalidade?+

Não. O valor de R$ 19,90 é pago uma única vez e a licença é permanente para um computador.

Posso criar mais de um usuário?+

Sim. Você pode criar vários perfis locais, cada um com senha e dados financeiros independentes.

Precisa de internet para funcionar?+

Não para o controle financeiro. A internet é necessária somente em etapas como compra e ativação da licença.

Onde ficam armazenados os dados?+

No próprio computador. O sistema também oferece backup para você guardar uma cópia dos registros.

Em quais computadores funciona?+

Esta versão foi desenvolvida para computadores com Windows. A licença é vinculada a uma máquina.

Como recebo o programa após a compra?+

Depois da aprovação do pagamento, o site libera o instalador e os dados necessários para ativação.
